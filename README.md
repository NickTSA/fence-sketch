# LA Fence Craft Sketch

The fence sketch app, ready for GitHub Pages. Build 2026-10-09.

| File | What it is |
|---|---|
| `index.html` | The app (PDF library built in, works offline) |
| `sw.js` | Keeps a copy on the phone/tablet for jobs with no signal |
| `manifest.json`, `*.png` | Home-screen icon and name |

**To update:** upload *all* of these files to the repository, replacing the old ones.
Open the site and check the build date at the bottom of the side panel. If it still
shows the old date, tap it once to fetch the new version - your sketch is kept.
